# Версия 5: наклейка внутри генерации и полный выезд

Подготовлены исходные изображения встроенным imagegen:

- `turn5.png`: наклейка «ЛогистРу» встроена в поверхность дверей до генерации видео; оба участника стоят на красный.
- `turn5.end.png`: тот же перекресток, зеленый свет, всадник на прежнем месте, машина полностью вне кадра.
- `turn5.prompt.txt`: полный промпт Veo — трогание вперед, правый поворот, полный выезд вправо, без исчезновения.

Два запроса Veo, включая повтор после паузы, отклонены: HTTP 429 RESOURCE_EXHAUSTED. Принятая операция не создана, нового видео пока нет. Причина по ответу API не уточнена: квота или биллинг. Дальнейшие автоматические повторы остановлены.

После восстановления доступа: `python output/veo-logistru-v2/produce.py submit turn5`, затем status/download и `edit.py inspect turn5`. До сборки проверить траекторию, полный выезд, неподвижность всадника и сохранность букв на наклейке. После визуальной проверки: `python output/veo-logistru-v2/finish_v5.py --reviewed`.

Финальный скрипт добавляет только текст на стационарный щит заправки. Наложения логотипа на автомобиль в этой версии нет. Согласованные две русские реплики и прозрачный логотип заставки сохранены.
