# Tabler Icons v3.46.0

The local SVG sprites contain the complete published Tabler Icons set: 5,130 outline icons and 1,054 filled icons. Community icons use an external `<use>` reference to these files, so no icon CDN or asset build is needed at runtime.

- `tabler-sprite-filled.svg`: https://cdn.jsdelivr.net/npm/@tabler/icons-sprite@3.46.0/dist/tabler-sprite-filled.svg
