Deploy on server (after deploy-git.bat / git push)
=================================================

Open PuTTY, Tabby, or Windows Terminal and connect:

  ssh logist_sys@24logist.ru

Paste these commands (all at once or line by line):

---
cd /var/www/logist_sys/data/24logistru
git pull origin main
sed -i 's/\r$//' script_ai/deploy-production.sh
DEPLOY_APP_DIR=/var/www/logist_sys/data/24logistru DEPLOY_BRANCH=main bash script_ai/deploy-production.sh
---

What the server script does:
  - composer install
  - npm install + npm run build
  - php artisan migrate --force
  - optimize:clear + config/route/view cache

Requires on server: PHP intl, Node.js + npm.

Site: https://24logist.ru

Kaspersky: add exclusions for ssh.exe, scp.exe (Git for Windows)
  usually: C:\Program Files\Git\usr\bin\ssh.exe
