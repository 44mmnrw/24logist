# SEO страниц сообщества

Админка: **Сообщество → SEO страниц**, URL `/admin/community-seo-pages`.

## Реестр ссылок

В реестр автоматически попадают главная сообщества, правила, конфиденциальность,
рубрики, темы, профили и постоянные служебные страницы. Поиск работает по названию
и пути; есть фильтр по типу страницы и открытие публичного URL.

Первое открытие списка добавляет существующие страницы. Далее изменения тем,
рубрик и профилей отслеживаются через `CommunitySeoObserver`. Повторное открытие
списка сверяет реестр с данными, в том числе добавленными импортом.

Настройки привязаны к ID сущности, поэтому изменение slug не теряет SEO.
Скрытые и мягко удалённые темы сохраняют настройки, но не попадают в sitemap.
После восстановления темы настройки применяются снова.

## Настройки

- Meta title, description, keywords, H1, robots и canonical.
- Open Graph: заголовок, описание, тип, изображение и alt.
- Twitter/X: тип карточки, заголовок, описание, отдельное изображение и alt.
- Schema.org: включение, тип страницы, headline, description и изображение.
- Включение в sitemap и предпросмотр поискового сниппета.

Пустое поле использует значение по умолчанию. Для старых тем сохраняются
существующие SEO-данные из `community_posts`; новые настройки имеют приоритет.
Редактор темы содержит ссылку на единую SEO-карточку.

H1 изменяет только заголовок открытой страницы, а не название темы/рубрики
в навигации. Описание поиска и OG description независимы.
Изображения сохраняются на public disk в `community/seo/{og,twitter,schema}`.

## Индексация

Служебные страницы остаются `noindex, nofollow` независимо от ручного значения.
Профили по умолчанию имеют `noindex, follow`; администратор может разрешить
индексацию публичного профиля. Поиск, сортировки и пагинация используют
`noindex, follow` с canonical на постоянную страницу без параметров.

Sitemap включает только публичные доступные страницы с разрешённой индексацией,
включённым флагом sitemap и собственным canonical. Внешний canonical не добавляется
в карту сайта. Сохранение настроек и изменение доступности сбрасывают её кеш.

Структурированные данные JSON-LD экранируют HTML-разделители. Для тем сохраняется
разметка DiscussionForumPosting с автором и датами; для профилей — ProfilePage.

## Развёртывание и проверка

Применить миграцию `2026_09_22_120000_create_community_seo_pages_table.php`
обычным процессом развёртывания. Сборка frontend для изменения не требуется.

Целевые проверки: `CommunitySeoTest`, `CommunityTest`,
`CommunityPostModerationTest`, `CommunitySettingsTest`, `BlogTest`.
Для запуска тестов в Windows рядом с работающим сайтом можно задать отдельный
`VIEW_COMPILED_PATH`, чтобы исключить конкуренцию за скомпилированные Blade-шаблоны.
