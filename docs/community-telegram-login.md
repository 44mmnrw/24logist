# Вход в сообщество через Telegram

Используется [официальный Telegram Login с OpenID Connect и PKCE](https://core.telegram.org/bots/telegram-login). Сайт перенаправляет посетителя на `oauth.telegram.org`, обменивает код на ID token и проверяет его подпись, издателя, получателя, срок действия и nonce. Пароль Telegram сайт не получает.

## Настройка

1. В `@BotFather` откройте настройки бота → Login Widget и добавьте разрешённые URL `https://24logist.ru` и `https://24logist.ru/community/auth/telegram/callback`.
2. Скопируйте выданные Client ID и Client Secret.
3. В админке сайта откройте «Настройки сайта» → «Сообщество 24Logist» → «Авторизация через Telegram». Вставьте Client ID и Client Secret. Redirect URI можно оставить пустым, поскольку приложение использует адрес callback выше. Если заполнить его, он должен точно совпадать с разрешённым адресом у `@BotFather`.
4. Сохраните настройки и проверьте вход в приватном окне через `/community/login`.

Кнопка Telegram показывается только когда раздел сообщества включён и заполнены оба OAuth-поля. Bot Token для входа не требуется; он нужен отдельно для доставки уведомлений через Telegram-бота. Секреты хранятся в настройках сайта в зашифрованном виде и не должны передаваться в чат или репозиторий.
