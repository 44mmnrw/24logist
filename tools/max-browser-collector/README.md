# Браузерный сборщик MAX

1. Создайте отдельный токен командой `php -r "echo bin2hex(random_bytes(24)), PHP_EOL;"`.
2. В админке ЛогистРу откройте настройки сообщества и сохраните его в поле «Новый токен сборщика».
3. Откройте `chrome://extensions`, включите режим разработчика и выберите «Загрузить распакованное расширение».
4. Укажите папку `tools/max-browser-collector`.
5. Откройте или обновите нужный групповой чат на `https://web.max.ru`.
6. Откройте расширение, вставьте тот же токен и выберите сценарий.
7. Нажмите «Собрать открытый чат» и не закрывайте окно расширения до завершения. Повторите для остальных источников сценария.
8. Нажмите «Сформировать черновики».

Расширение передаёт только текст сообщений и псевдонимизированный ключ автора. Телефоны, email, ссылки, упоминания и государственные номера заменяются маркерами до отправки. Сессия и cookies MAX никуда не передаются.
