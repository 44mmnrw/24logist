# Браузерный сборщик MAX

1. Создайте отдельный токен командой `php -r "echo bin2hex(random_bytes(24)), PHP_EOL;"`.
2. В админке логистРу откройте настройки сообщества и сохраните его в поле «Новый токен сборщика».
3. Установите расширение одним из способов ниже.
4. Откройте или обновите нужный групповой чат на `https://web.max.ru`.
5. Нажмите значок расширения: сборщик откроется в отдельной постоянной вкладке. Вставьте токен и выберите сценарий.
6. Для обычного сценария нажмите «Собрать открытый чат». Для сценария «Пост из чата + обсуждение» нажмите «Собрать обсуждение поста». Не закрывайте окно расширения до завершения.
7. Нажмите кнопку формирования черновиков. В сценарии с исходным постом она называется «Создать тему и обсуждение».

## Chrome

1. Откройте `chrome://extensions`.
2. Включите режим разработчика.
3. Нажмите «Загрузить распакованное расширение» и укажите папку `tools/max-browser-collector`.

## Firefox

1. Откройте `about:debugging`.
2. Выберите «Этот Firefox».
3. Нажмите «Загрузить временное дополнение».
4. Откройте папку `tools/max-browser-collector` и выберите файл `manifest.json`.
5. После установки обновите вкладку `web.max.ru`.
6. Нажмите значок расширения — панель откроется в отдельной вкладке и не исчезнет при переключении на MAX.

В обычном Firefox временное дополнение отключается после перезапуска браузера. Для постоянной установки необходим подписанный Mozilla файл XPI.

Расширение передаёт только текст сообщений и псевдонимизированный ключ автора. Телефоны, email, ссылки, упоминания и государственные номера заменяются маркерами до отправки. Сессия и cookies MAX никуда не передаются.
